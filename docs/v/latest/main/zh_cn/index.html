      这是MieHex:Revolution文档的在线版本。

      此版本是根据GitHub上最新代码构建而来的。其中可能包含游戏内暂未实装的新特性，就连Modrinth和CurseForge上的最新版本里也找不到！

      条目的模糊处理相当于剧透警告。点击条目即可取消模糊，不过这么做有可能破坏游戏后期的进程与体验。也可点击此处以取消所有模糊。


      往事犹若异乡；他们在那里做的事情都不一样。

                      灵魂投射

                      灵魂投射 (entity →)

                      • 渲染方式
                        • 配色
                          浏览器不支持图案的可视化。图案代码见此：wqqqqwqedwwde

                          借由将一小片灵魂投射进同一维度的实体中，便可以共享那个实体的视野。只有卷轴、悦灵、咒法师以及一些空灵的实体才可以作为目标，以自己作为目标施法可以复原。消耗5份紫水晶粉。值得注意的是，在咒法师以实体的视野观察时，无法看见自己。


                          灵质之纯化 (player →)

                          • 渲染方式
                            • 配色
                              浏览器不支持图案的可视化。图案代码见此：qwawqwaqewdwewd

                              获取目标玩家现在灵魂投射的实体，如果返回了那个玩家本身，那么则会承受意识的怒火。

                              法术书法术

                              学者之翻页 (int →)

                              • 渲染方式
                                • 配色
                                  浏览器不支持图案的可视化。图案代码见此：qqadad

                                  将一缕意志注入副手的法术书中，我便无需动手即可翻阅其页。接受一个自然数，将法术书向前翻动指定页数。需要副手持有法术书。


                                  区块加载

                                  时之锚 (vector, int →)

                                  • 渲染方式
                                    • 配色
                                      浏览器不支持图案的可视化。图案代码见此：aawewewaqweedeewqawewe

                                      我将一片空间锚定在世界之心跳的节拍上，令其在时限内保持加载。接受一个坐标向量和一个以刻为单位的持续时间。坐标所在之区块将被保持加载指定的时长。媒质消耗随持续时间递增。


                                      理念方块

                                      构筑理念方块 (vector →)

                                      • 渲染方式
                                        • 配色
                                          浏览器不支持图案的可视化。图案代码见此：wqaqqqqqeawqwqwqwqwqw

                                          我用理念构建方块，使其能够模仿其他方块的外形。接受一个坐标向量，在指定位置生成一个理念方块。放置后，手持任意方块右键即可改变其外观，空手潜行右键则可将其还原。

                                                      卓越法术

                                                      这类法术据信极难施放，但也极为强力。记载它们的文献极为少见（据称理由充分）。这也许只是某些消亡的老古董口中的胡言乱语，不过——它们只是简单的图案罢了。

                                                      虚空之手 卓越型

                                                      虚空之手 卓越型 (entity, boolean →)

                                                      • 渲染方式
                                                        • 配色
                                                          浏览器不支持图案的可视化。图案代码见此：dwqqwqwqwaweaqqqqedwqqwqwqwaqeeedqaedwqqwqwqwaweaqqqq

                                                          我延伸我的触及，跨越虚空与遥远的实体互动。接受一个实体和一个布尔值。若为真，则攻击目标实体；若为假，则对目标实体模拟右键交互。媒质消耗随水平距离指数增长。


                                                          这是一个卓越法术。其媒质消耗为 2 的施法者到目标的两个水平轴向距离之和的次方数目的万分之一紫水晶粉，仅考虑水平距离，每多一格消耗便翻一倍。对于亲密交流或远程惩戒均颇为有效。
