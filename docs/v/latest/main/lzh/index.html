      理念碎片

      借不易之永恆理念，跨寥廓而彰人力奇工。


      理念碎片者，乃飽浸媒質之淬靈晶碎片也，中可銘鑄一 Iota 並一串圖印。持碎片而施正律（右鍵），即馳發其中銘刻之法術；若所儲之 Iota 為向徑或實體，縱去千萬里之遙，彼處皆視同身處法域。既施其術，碎片自隕。諸般媒質之費，悉由碎片自蓄承之，直折紫水玉粉三十數。

                              刻印集 Iota

                              運化諸咒之際，每頻徵重復之操演，或引入相同之 Iota；致余裁撰法印之時，往往重描繁複圖列，或翻檢於核心、結念繩堆簇之中，以列序之術嵌置諸物。久居瑣碎，余心實厭苦之。

                              幸蒙上蒼垂顧，余得於古卷秘藏之中，偶悟一異巧 Iota——是謂刻印集 Iota。論其體骨，乃定製圖印對屬特定 Iota 之一一符契之總會也。


                              此符得為赫爾墨斯之策略直行演運，既行其術，即入“刻印集適位”之境。居此境者，凡起列於刻印集中之圖印（迴旋有別）運演之時，自得履行其對應之 Iota（若其可行），或收納該 Iota 入棧（若其不可行）。若未嘗有刻印集施行，則權作奉行一虛靈空集。治刻印集及其適位之圖符，悉載於後。
